# ✅ To-Do List Web App

A clean, responsive to-do list app built with vanilla **HTML, CSS, and JavaScript** — a hands-on exercise in DOM manipulation.

## ✨ Features

- ➕ Add tasks
- ✔️ Mark tasks complete
- 🗑 Delete tasks
- 📅 Current-date display
- 🎨 Clean, responsive UI

## 🛠 Tech Stack

- **HTML · CSS · JavaScript** — no frameworks, no build step

## 🚀 Run it

Open `index.html` in any browser.

## 📌 Note

Tasks are kept **in memory** — they reset when the page reloads (localStorage persistence is a planned upgrade).
